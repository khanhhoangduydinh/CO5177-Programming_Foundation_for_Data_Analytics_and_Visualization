06 — NUMERICAL FEATURE DISTRIBUTIONS

KEY INSIGHTS / CONTINUOUS FEATURES

Orbital period: median 9.75 days, but the upper tail reaches about 130,000 days; a log axis is required.

Planet radius: median 2.39 Earth radii with extreme catalogue values; robust preprocessing is safer than deletion.

Stellar temperature: most hosts cluster around the median of 5,767 K, with fewer very cool or hot stars.

Outliers: scientifically rare objects can be valid observations, so they remain available to the tree model.

07 — CATEGORICAL FEATURE DISTRIBUTIONS

KEY INSIGHTS / CATEGORICAL FEATURES

Target: false positives form a narrow majority (50.60%), while candidates are the smallest and most ambiguous class.

TCE delivery: DR25 dominates the table, so rare release categories receive little independent statistical support.

Names and IDs: object names identify rows but carry no transferable physical signal and are excluded.

Vetting fields: pipeline disposition and false-positive flags are intentionally excluded because they encode the answer.

12 — KEY INSIGHTS

  • The KOI catalogue satisfies every tabular-data constraint in the assignment.

  • The extended model raises validation macro F1 from 0.558 to 0.758.
  • Candidates remain scientifically ambiguous and are the hardest class to predict.
  • Model importance describes predictive utility, not physical causality.
  • Predictions support review priorities; they do not establish planetary confirmation.
